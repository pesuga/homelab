# Temporary Documentation

This folder contains **work‑in‑progress** documentation that supports ongoing development tasks. Files here are not meant to be permanent. Once the related feature or fix is completed, either:

- Move the relevant content to `project-context` (e.g., architecture decisions, service updates), **or**
- Delete the file if it is no longer needed.

## How to use
- Add a header `# Temporary Documentation` at the top of each file.
- Include a comment `<!-- TODO: migrate or delete -->` to remind reviewers of its temporary nature.
- When the work is done, run the cleanup script `/scripts/keep/cleanup-docs.sh` (to be created) or manually relocate/delete the file.
